## Projetos

### Spatium (2026) — Tauri · Rust · React
[github.com/Zelphh/Spatium](https://github.com/Zelphh/Spatium)

App desktop para cronometrar e categorizar horas de foco. Front-end em React + TypeScript, back-end em Tauri + Rust, persistência em SQLite local. Timer com três modos (padrão, pomodoro e personalizado), atalhos globais e execução em segundo plano. Duração calculada a partir de um log de eventos da sessão (started/paused/unpaused/finished), o que permite restaurar sessões interrompidas sem perder tempo. Back-end organizado em comandos, serviços e repositórios, com migrações versionadas e views SQL para histórico e estatísticas.

### DSCommerce (2024) — Java · Spring Boot · JWT
[github.com/Zelphh/dscommerce](https://github.com/Zelphh/dscommerce)

API REST de e-commerce com Spring Boot, Spring Data JPA e H2. CRUD de produtos, categorias e pedidos; catálogo paginado com busca por nome e categoria e consultas otimizadas (join fetch, projections). Autenticação e autorização com Spring Security (authorization + resource server), OAuth2 com password grant customizado, BCrypt e JWT com roles (usuário/admin). Tratamento centralizado de erros (404, 422, 403). Front-end simples em HTML/CSS/JS consumindo a API. Desenvolvido 100% sem IA.

### Conway's Game of Life (2025) — Python · Pygame
[github.com/Zelphh/conway-s-game](https://github.com/Zelphh/conway-s-game)

Projeto final do CS50x. Autômato celular com NumPy e Pygame, tabuleiro editável durante a simulação, controle de FPS e salvamento/carregamento do estado em JSON.

### Filter (2024) — C
[github.com/Zelphh/cs50](https://github.com/Zelphh/cs50)

Programa de linha de comando que aplica filtros em imagens BMP: escala de cinza, espelhamento, desfoque e detecção de bordas (Sobel), manipulando a matriz de pixels diretamente. Desenvolvido sem IA.
